One image that sums up the world's news of Thursday, 19 November 2026: the first-ever Trump–Xi–Putin summit in Shenzhen, three oil tankers ablaze off the Strait of Hormuz, GTA VI's worldwide launch, and the day's other top stories — drawn as a one-page newspaper front page, "THE WORLD".

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `entry.png` to the output directory. The front page itself is composed by `compose.py` (Pillow + DejaVu fonts) from three illustration panels generated for this entry, with every headline, label and caption drawn in code.

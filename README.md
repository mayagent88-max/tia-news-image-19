## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `entry.png` to the output directory. The front page is drawn entirely in code (Pillow + DejaVu fonts): every illustration, headline, label and caption is drawn by the program, and every story on it was first reported on Thursday 19 November 2026.
